# Pinout (ESP32 DevKit ทั่วไป ยังไม่ได้ทดสอบกับบอร์ดจริง)

## Sensor node (box_A, box_B ต่อเหมือนกัน)
| อุปกรณ์ | ขา | หมายเหตุ |
|---|---|---|
| DHT22 DATA | GPIO4 | pull-up 10k ไป 3V3 |
| Reed switch | GPIO33 | อีกข้างลง GND, INPUT_PULLUP, เป็นขา RTC |
| จัมเปอร์ OTA | GPIO32 | ต่อ GPIO32 กับ GND ตอนบูต = เข้าโหมด OTA (ไม่ต่อ = ทำงานปกติ) |
| ไฟเลี้ยง | VIN/GND | 5V |

โค้ดสมมติว่าประตูปิด = สวิตช์ติดแม่เหล็ก = LOW ถ้าต่อกลับด้าน ให้แก้ `doorOpen()`

## Gateway
| อุปกรณ์ | ขา | หมายเหตุ |
|---|---|---|
| DS18B20 DATA | GPIO16 | pull-up 4.7k ไป 3V3 |
| LDR | GPIO34 | ตัวแบ่งแรงดัน LDR + 10k (ADC1) |
| MQ-135 AO | GPIO35 | ตัวแบ่งแรงดัน 10k + 15k ลง GND (ADC1) |
| พัดลม A (MOSFET gate) | GPIO26 | 100Ω ที่ gate, pull-down 10k |
| พัดลม B (MOSFET gate) | GPIO27 | เหมือน A |
| ไฟเลี้ยง | VIN/GND | 5V >= 2A |

## วงจรขับพัดลม (ต่อชุดละ 1 พัดลม)
GPIO -> 100Ω -> gate; gate -> 10k -> GND; drain -> ขั้วลบพัดลม; source -> GND;
ขั้วบวกพัดลม -> 5V/12V; ไดโอด 1N5819/1N4007 คร่อมพัดลม (cathode ไปขั้วบวก); GND ทุกส่วนร่วมกัน
ใช้ logic-level MOSFET ตรวจ datasheet ว่าเปิดเต็มที่ 3.3V (ไม่ใช้โมดูล IRF520)

## ข้อควรระวัง
- MQ-135 AO ให้แรงดันได้ถึง 5V ต้องผ่านตัวแบ่งแรงดันก่อนเข้า ESP32
- ใช้ขา ADC1 เท่านั้น (ADC2 ใช้ไม่ได้ตอนเปิด Wi-Fi)
- node และ gateway ต้องอยู่ช่อง Wi-Fi เดียวกัน
- ต้องเจาะผนังกล่องให้สายพัดลมลอด ใช้ cable gland หรืออุดให้แน่น ไม่งั้นความชื้นรั่วเข้า
