# แผนทดสอบ (เจ้าของ: Methasit) ใช้เป็นแม่แบบ กรอกผลจริงระหว่างทำ

หมวดนี้ได้คะแนนตามเกณฑ์: Test Plan (ปกติ + edge + failure พร้อมขั้นตอนและผล), Metrics (>= 3 อย่าง วัดจริง
ระบุวิธีวัด + ทำซ้ำและรายงาน min/max), Analysis (เทียบกับ objective และกับระบบที่มีอยู่ด้วยตัวเลขที่วัดเอง)

## 3) ตัวเลือกเพิ่ม: กล่องควบคุม
วัด RH ของกล่องที่ใช้ซิลิกาเจลอย่างเดียว (ไม่มีพัดลม/AI) เทียบกับกล่องระบบเรา ใช้ตอบ Q&A ว่าระบบเพิ่มอะไร
(ตัดสินใจก่อนว่ากล่องควบคุมนับเป็น node หรือไม่ เพื่อไม่ให้กระทบคะแนน Scalability)
