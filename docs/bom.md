## ที่แนะนำเพิ่ม (ไม่ได้อยู่ใน proposal)
- กล่องเล็กเจาะรูสำหรับใส่ซิลิกาเจล (ให้ลมผ่านเนื้อเจลจริง) แทนถุงตาข่ายอย่างเดียว
- cable gland หรือยางรองสายไฟ สำหรับรูที่สายพัดลมลอดผนังกล่อง
- terminal block / female header เพื่อไม่ต้องบัดกรีลงบอร์ดที่ยืมมา
- จัมเปอร์ 1 เส้นต่อ node สำหรับโหมด OTA (GPIO32-GND)
